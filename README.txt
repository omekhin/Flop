ФЛОП — как выложить сайт
========================

Что в папке:
  index.html    — главная (лендинг)
  play.html     — стол с ботами и тренером
  pushfold.html — тренажёр пуш/фолд
  calc.html     — калькулятор шансов рука против руки
  outs.html     — тренажёр аутов
  guide.html    — шпаргалка
  stats.html    — моя статистика и серия дней
  privacy.html  — политика конфиденциальности
  site.js       — серия дней + Яндекс Метрика и баннер про cookies (пока выключены)
  site.css, ranges.js — общие стили меню и таблицы диапазонов
  fonts/, fonts.css, favicon.svg — шрифты и иконка, всё лежит локально

Сайт не собирает никаких данных: статистика игроков хранится в их браузере.

ПЕРЕД ВЫКЛАДКОЙ
1. privacy.html: впиши ФИО, ИНН (после оформления самозанятости) и почту вместо [скобок].
2. Если хочешь другое название вместо «Флоп» — замени слово во всех .html.

ВАРИАНТ А. Быстрый тест на Netlify (5 минут, бесплатно)
1. Зайди на app.netlify.com и зарегистрируйся (через почту или GitHub).
2. Sites → Add new site → Deploy manually.
3. Перетащи эту папку целиком в окно браузера.
4. Через минуту получишь адрес вида что-то.netlify.app. Открой его с телефона
   на мобильном интернете (лучше у двух разных операторов) — проверь, что грузится.
5. Свой домен: Domain management → Add domain, дальше Netlify покажет,
   какие записи прописать у регистратора.

ВАРИАНТ В. GitHub Pages (бесплатно, у друга открывается с мобильного)
1. Зарегистрируйся на github.com.
2. New repository → имя, например poker-trener → Public → Create.
3. «uploading an existing file» → перетащи ВСЁ содержимое этой папки (включая файл CNAME
   и папку fonts) → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
5. Там же в Custom domain должно стоять poker-trener.ru (его подхватит файл CNAME).
6. В Beget в разделе DNS для poker-trener.ru поставь четыре A-записи @:
   185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
   и CNAME для www → твой-логин.github.io
7. Через 10–60 минут в Settings → Pages включи галочку Enforce HTTPS.
Новую версию сайта заливаешь так же: Add file → Upload files → перетащить файлы.

ВАРИАНТ Б. Российский хостинг (надёжнее для игроков из РФ)
Подойдёт любой хостинг со статическими сайтами: Beget, Timeweb, REG.RU
или Yandex Cloud Object Storage. Порядок везде одинаковый:
1. Купи домен (с автопродлением) и самый дешёвый тариф хостинга.
2. Загрузи содержимое папки в корень сайта (обычно public_html)
   через файловый менеджер в панели хостинга.
3. Включи бесплатный SSL-сертификат (Let's Encrypt) в панели.
4. Проверь сайт с телефона.

ЯНДЕКС МЕТРИКА (когда сайт заработает на своём домене)
1. metrika.yandex.ru → Добавить счётчик → укажи домен.
2. Скопируй номер счётчика и впиши его в site.js:  var METRIKA_ID = '12345678';
3. Перезалей site.js. Баннер про cookies включится сам.

ОФЛАЙН И «НА ЭКРАН ДОМОЙ»
Сайт ставится на телефон как приложение: в Safari «Поделиться → На экран Домой»,
в Chrome «Установить приложение». После первого открытия работает и без интернета.
Новые версии подтягиваются сами при следующем открытии.
