# Домашний дашборд

Сервер на макбуке собирает данные и отдаёт одну страницу: на телевизоре она во весь экран, на телефоне — в одну колонку.

| Плитка | Откуда данные | Как часто |
|---|---|---|
| Часы | часы макбука | каждую секунду |
| На улице | Open-Meteo (бесплатно, без ключа) | 15 мин |
| Дома | датчик Xiaomi с прошивкой pvvx по Bluetooth | по мере вещания датчика |
| Накопления | котировки Мосбиржи × ваши позиции + вклады из config.json | 5 мин |
| Траты | быстрая команда «Трата» на айфоне | сразу |
| Шаги | автоматизация «Команд» из «Здоровья» | по расписанию |
| Встречи | публичная ссылка календаря iCloud | 10 мин |

Файлы: `server.py` — сервер, `static/index.html` — страница, `config.json` — все настройки, `data/` — записанные траты, шаги и история накоплений.

---

## 1. Запуск на макбуке

1. Положите папку `dashboard` куда угодно, например в `~/dashboard`.
2. Откройте `config.json` и заполните:
   - `token` — любой длинный пароль. Его будут присылать команды с айфона.
   - `weather` — город и координаты (по умолчанию Москва).
   - `deposits` и `debts` — вклады, займ Дане и долги (раздел 2а).
   - `calendars` — ссылка на календарь (раздел 5).
   - `spend_budget_month` — бюджет на месяц, если хотите полосу «сколько осталось». `0` — без бюджета.
3. В «Терминале»:
   ```
   cd ~/dashboard
   ./start.sh
   ```
   При первом запуске он сам поставит зависимости. Откройте http://localhost:8765.

Посмотреть внешний вид без настроек: `DASH_MOCK=1 python3 server.py` (тестовые данные).

## 2. Проверка портфеля

Позиции уже вписаны со скриншотов: брокерский счёт (13 акций, 8 облигаций, фонд AKMM, 564,41 ₽) и ИИС (ОФЗ 26252 × 435, 626,45 ₽). Суммы на дату скриншота: брокерский ≈ 626 292 ₽, ИИС 397 233 ₽.

Сервер сам находит каждую бумагу на бирже и проверяет её по сумме со скриншота (`ref_value`): бумагу, которая не сходится по стоимости, он не возьмёт. Пока бумага не найдена, в расчёт идёт сумма со скриншота, а внизу плитки «Накопления» она перечислена как «без котировки».

После первого запуска откройте http://localhost:8765/api/positions: там видно, с чем сопоставлена каждая позиция (`secid`, `moex_name`).

**Скорее всего, сами не найдутся корпоративные облигации** (Селигдар, Атомэнергопром, Синара, Сбер SBER51): у эмитента бывает несколько выпусков рядом с номиналом. Тогда:
- в приложении Альфы нажмите на облигацию и найдите ISIN (вид `RU000A...`);
- впишите его в `config.json` в поле `"secid"` этой позиции;
- перезапустите сервер с ключом `--rematch`: `.venv/bin/python server.py --rematch`.

Поиск из терминала: `.venv/bin/python server.py --find Селигдар`.

Когда купите или продадите бумаги, поправьте `qty` и `ref_value` и запустите с `--rematch`.

НКД по облигациям входит в сумму, как в итоге счёта у Альфы.

## 2а. Вклады, займ и долги

Главная цифра — **капитал**: всё, что есть, минус долги. Проценты по вкладам и займу начисляются сами каждый день.

В `deposits` у каждой строки есть:
- `amount` — сумма, `rate` — ставка в % годовых;
- `accrual: "daily"` — проценты каждый день с капитализацией (Яндекс). Здесь `amount` — остаток на дату `from`. Если сверяете с банком, впишите новый остаток и новую дату;
- `accrual: "simple"` — проценты в конце срока (Альфа, займ Дане), с `from` по `to`. На дашборде видно, сколько уже набежало и сколько будет к концу срока;
- `"kind": "loan"` — выданный займ. Если срок прошёл, а запись осталась, дашборд это отметит.

В `debts` — текущие долги по кредиткам. Их нужно обновлять вручную, когда долг меняется.

Начисленные проценты — расчётные: налог и досрочное закрытие не учитываются.


## 2б. Сверка раз в месяц

Сервер каждый день сохраняет снимок капитала в `data/history.json`. Правки `config.json` старые дни не трогают, они меняют значения только с сегодняшнего дня. Перезапускать сервер не нужно: через несколько секунд после сохранения файла он перечитает настройки сам. Если в файле ошибка, сервер продолжит работать на старых настройках и покажет строку с ошибкой внизу плитки «Капитал».

Что обновить:
- **Бумаги:** `qty` по каждой бумаге и `cash` по счёту. Новую бумагу допишите строкой с `secid` (тикер или ISIN облигации), проданную удалите. `ref_value` нужен, только если бумагу ищут по `query`.
- **Вклад Яндекс:** `amount` = остаток по приложению банка, `from` = сегодняшняя дата. Без нового `from` проценты за прошедшие дни посчитаются второй раз.
- **Вклад Альфа и займ:** не трогайте до закрытия или погашения. Новый вклад — новая строка.
- **Кредитки:** текущий долг в `amount`.

Строка под капиталом раскладывает изменение с начала месяца:
- **биржа** — переоценка бумаг;
- **проценты** — начисления по вкладам и займу;
- **пополнения и долги** — всё остальное: зарплата, отложенная на вклад или брокерский счёт, погашение кредиток, снятия.

Покупка бумаг на деньги со счёта сюда почти не попадает, если вы обновили и `qty`, и `cash`: деньги просто превратились в бумаги. Если сервер был выключен, движение рынка за пропущенные дни попадёт в «пополнения и долги».

## 3. Чтобы работало постоянно

**Не засыпать.** `start.sh` уже держит макбук бодрым через `caffeinate`. С закрытой крышкой мак работает только на питании и с подключённым телевизором.

**Автозапуск после перезагрузки:**
1. В файле `ru.home.dashboard.plist` замените `ПУТЬ_К_ПАПКЕ` на полный путь, например `/Users/ilya/dashboard`.
2. Выполните:
   ```
   cp ru.home.dashboard.plist ~/Library/LaunchAgents/
   launchctl load ~/Library/LaunchAgents/ru.home.dashboard.plist
   ```
   Лог: `data/server.log`.

**Телевизор во весь экран:**
```
open -a "Google Chrome" --args --kiosk http://localhost:8765
```
Это можно добавить в «Объекты входа». С 23:00 до 7:00 экран приглушается, а раз в 10 минут картинка сдвигается на пару пикселей, чтобы не выгорала.

**Браузер в телевизоре:** откройте `http://<IP-макбука>:8765`. IP — в «Настройки → Wi-Fi → Подробнее». Чтобы адрес не менялся, закрепите его за макбуком в настройках роутера.

## 4. Доступ с телефона откуда угодно — Tailscale

1. Поставьте Tailscale на макбук и айфон, войдите в один аккаунт.
2. В приложении Tailscale на маке посмотрите имя макбука, например `macbook.tail1234.ts.net`.
3. На айфоне откройте `http://macbook.tail1234.ts.net:8765` → «Поделиться» → «На экран „Домой“». Получится иконка, которая открывается как приложение.

Наружу в интернет дашборд не открыт: его видят только ваши устройства в Tailscale и устройства в домашней сети. Читать страницу может любой в вашем Wi-Fi, а записывать — только тот, у кого есть токен.

Для команд ниже используйте тот же адрес Tailscale: он работает и дома, и вне дома, пока Tailscale включён (в настройках можно включить «Подключаться по запросу»).

## 5. Календарь iCloud

На маке в «Календаре»: правый клик по календарю → «Поделиться» → поставить «Публичный календарь» → скопировать ссылку `webcal://...` и вставить в `calendars`. Календарей можно добавить несколько.

Учтите: по публичной ссылке календарь видит любой, у кого она есть. Ссылка длинная и случайная, но лучше не публиковать так рабочий календарь со служебными деталями.

## 6. Команды на айфоне

Ниже `АДРЕС` — это `http://macbook.tail1234.ts.net:8765`, `ТОКЕН` — пароль из `config.json`.

### «Трата» — записать сумму вручную
1. «Запросить ввод» → тип «Число», вопрос «Сумма».
2. «Запросить ввод» → тип «Текст», вопрос «На что» (можно пропустить этот шаг).
3. «Получить содержимое URL»:
   - URL `АДРЕС/api/spend`, метод **POST**;
   - Заголовки: `X-Token` = `ТОКЕН`;
   - Текст запроса **JSON**: `amount` = «Введённое число», `note` = «Введённый текст».
4. «Получить значение для ключа» `message` в «Содержимое URL».
5. «Показать уведомление» — значение из шага 4. Придёт «Записал 450 ₽. За месяц: 31 200 ₽».

Вынесите команду на экран «Домой», в виджет или на кнопку действия.

### «Отменить трату»
«Получить содержимое URL» → `АДРЕС/api/spend/undo`, POST, тот же заголовок `X-Token`. Удаляет последнюю запись.

### «Шаги» — автоматически
1. «Найти образцы Здоровья»: тип «Шаги», дата начала «Сегодня», **группировать по «День»**, лимит 1.
2. «Получить содержимое URL» → `АДРЕС/api/steps`, POST, `X-Token` = `ТОКЕН`, JSON: `steps` = «Образцы Здоровья».

Затем «Автоматизация» → «Время суток»: сделайте несколько автоматизаций (например, 10:00, 13:00, 16:00, 19:00, 22:00), выберите «Запускать сразу». Почасовых автоматизаций в iOS нет.

Если на дашборде шагов больше, чем в «Здоровье», значит сложились шаги с часов и телефона. Проверьте, что включена группировка по дню. Ещё одно ограничение: пока айфон заблокирован, «Здоровье» не отдаёт данные, и такой запуск пропускается — следующий подхватит.

## 7. Датчик температуры и влажности

Ritmix данные не передаёт, поэтому нужен Xiaomi Mijia **LYWSD03MMC** (квадратный, с экраном).

1. На макбуке в Chrome откройте прошивальщик pvvx: https://pvvx.github.io/ATC_MiThermometer/TelinkMiFlasher.html
2. «Connect» → выберите датчик → «Do Activation» → загрузите прошивку `ATC_...bin` (кнопка на странице) → «Start Flashing».
3. После перезагрузки датчика снова подключитесь и в настройках выберите тип рекламы **Custom (pvvx)** («Advertising type»), затем «Send Config».
4. Поставьте библиотеку Bluetooth: сначала инструменты разработчика `xcode-select --install`, затем `.venv/bin/pip install bleak`.
5. В `config.json` поставьте `"indoor_sensor": { "enabled": true, "name_prefix": "ATC_" }` и перезапустите сервер.
6. macOS спросит доступ к Bluetooth для «Терминала» — разрешите. Если не спросил: «Настройки → Конфиденциальность → Bluetooth».

Датчик вещает раз в несколько секунд, макбук ловит его в пределах квартиры. Плитка «Дома» подскажет, если воздух слишком сухой или влажный (нормой считается 30–60%), и если садится батарейка.

## Если что-то не так

- **Красная пометка в углу плитки** — данные устарели или пришла ошибка. Наведите мышь, чтобы прочитать текст, или смотрите `data/server.log`.
- **Ошибка SSL при запросах** — Python с python.org: запустите `Install Certificates.command` из папки Python в «Программах». `start.sh` и так ставит `certifi`, обычно этого хватает.
- **Команда отвечает «неверный токен»** — сверьте заголовок `X-Token` с `token` в `config.json`.
